## 🚀 What is Whispra?

Whispra is a desktop app that translates voice chat in **real time**.  
It listens to your mic or speakers, detects language, translates it instantly, and plays it back — so you can communicate across languages seamlessly.

## 📖 Usage

1. Download the installer from [Releases](https://github.com/YOUR_ORG/whispra-download/releases/latest).  
2. Run the installer and follow the on-screen steps.  
3. Launch **Whispra** and sign in (or create an account).  
4. Choose your input/output devices and start translating in-game or in voice chat.

## 🔑 Key Features

- 🎙 **Live voice translation** — translate while you speak or listen  
- 🖥 **Overlay mode** — see captions alongside translations  
- 🎮 **Optimized for gaming** — low-latency, lightweight, background friendly  
- 🌍 **Multilingual** — support for dozens of languages
